# Шутис(с): новые маршруты — отчёт агента №2 (30.10.2026)

Итог: отец Эльвиры (Иосиф Шутис/Шутисс) в новых источниках **не найден**. Главный новый результат отрицательный: в проиндексированных «Вся Москва» 1915–1936 гг. фамилии Шутис/Шутисс нет ни в одном написании. Попутно сделано два наблюдения:
- Все дореволюционные военные упоминания Шутисов относятся к **Шавельскому уезду** (северная Литва).
- Рижские «Sutis» — **другая фамилия**, их нельзя путать с Шутисами.

Регистры дела не менялись.
