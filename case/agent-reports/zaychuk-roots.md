# Зайчук — происхождение Павла (отца Галины) и Феклы: отчёт агента, 31.10.2026

Цель: проверить гипотезу «Павел Зайчук из Халаим-Городка», найти доступные метрики/списки по очагам фамилии. Живых не искали. Реестры дела не правились.

**Итог коротко.** Прямой записи о Павле (отце Галины) и Фекле не найдено. Установлено:
1. «Холымгородок / Халаим-Город» = с. **Халаїмгородок** (с 1946 Городківка, ныне Андрушівська громада Бердичівського р-ну Житомирської обл.); до 1917 — Білопільська (ранее Халаїмгородоцька) вол. **Бердичівського** пов. Київської губ.; в 1935–1946 — **Вчорайшенський р-н** (Київ., с 1937 Житомир. обл.). Пометка «Таращанский р-н» в ПН — ошибка индексации: в оригинале донесения читается «[предположительно: Чорашинский] р-н» (= Вчерайшанский). Значит, **это не тот же очаг, что Красилівка Таращанського пов.** (Яндекс-архив) — очагов фамилии два.
2. В Халаїмгородку большой куст Зайчуков (ПН + «Реабілітовані історією»), см. §1.2. Павла среди них нет; есть «Павел» как отец Федора (1910).
3. Метрики Халаїмгородка 1896–1919 существуют (ДАЖО ф.1 оп.77, в томах **Житомирського** повіту, буква Х), но сканы — только на FamilySearch (нужен вход). На Commons их нет (кроме 1918 г., где села нет).
4. Перепись 1897 (ДАКО 384-4-107, Commons): по Халаїмгородку там только сводная обложка, **поимённых листов села нет**; листы соседнего с. Камені просмотрены сплошь — Зайчуков нет (§1.4).
