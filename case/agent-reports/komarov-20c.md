# Комаровы, XX век: Наталья Алексеевна, Егор Петрович, Николай Егорович, вдова Федора

Агент-отчёт, 31.10.2026. Реестры и CSV не менялись. Яндекс-архив, «Память народа» и e-poisk не трогал. Openlist в браузере тоже не открывал: расширение Chrome запрещает этот домен.

## 0. Главное

- **Прямых находок по четырём целям нет.** Девичью фамилию Натальи Алексеевны и судьбу Егора после 1923 года по открытым внешним базам установить не удалось. Это значит «не найдено в проверенных базах», а не «не было».
- **Важная поправка к маршрутам: административная привязка Телешова.** По ru.wikipedia, статья «Телешовский сельсовет (Коммунистический район)»:
  - до 1954 года Телешово было центром **Телешовского сельсовета**;
  - в 1929 году сельсовет отошёл к Дмитровскому району;
  - с **27.02.1935 по 1954 год** он был в **Коммунистическом районе** Московской области (центр — Хлебниково, затем Рогачёво; район существовал в 1929–1957 годах).
  - В 1926 году в сельсовет входили Бородино, Куракино, Романцево, Телешово, Худякино, Черных и Куракинский хутор; население сельсовета — 1071 человек по переписи 1926 года.

  Поэтому для 1935–1954 годов искать нужно с пометками «**Коммунистический р-н**», «**Коммунистический РВК**» и «**Рогачевский райотдел НКВД**», а не «Дмитровский». Пример — «Бутовский полигон. В родном краю» (2004, с. 275): «Рогачевский райотдел НКВД Московской области» в 1937 году.
- Для репрессий проверены «Жертвы политического террора» (архивная копия 2019 года) и «Бессмертный барак». **Комаровых из Телешова или Телешовского сельсовета нет**, Егора/Георгия Петровича и Натальи Алексеевны тоже нет. Есть один однофамилец из Коммунистического района, он не наш (см. п. 1).

## 3. Блокировки

- **openlist.wiki:** 403 для curl и WebFetch, расширение Chrome запрещает чтение домена. Маршрут для пользователя: поиск «Телешово» и «Комаров Егор» в его браузере.
- **lists.memo.ru / base.memo.ru:** не открываются, использован снимок 2019 года. Позднейшие добавления не проверены.
- **Ваганьковское:**
  - официальный поиск места захоронения (mos.ru / ГБУ «Ритуал») требует входа и не открылся из моей сети;
  - polk.mos.ru и rgis.mosreg.ru: таймаут или TLS-ошибка;
  - e-poisk запрещён;
  - открытой базы захоронений Ваганьковского без входа не найдено.
- **«Память народа» / ОБД / Книга памяти Московской обл. (ВОВ):** сканы книги есть только внутри ПН — это часть пользователя.
- Мелочь: в этой среде `curl` — псевдоним `curlie`, он шлёт POST с телом из stdin. Использовать `/usr/bin/curl`.

## 4. Следующие шаги (по пользе)

1. **Цель 1, девичья фамилия.** Брак Егора и Натальи 1921–22 годов в оцифровке ЦГАМО есть только частично (браки Рогачевского ВИК — только 1920, №103–198).
   - (а) **[пользователь, Яндекс-архив]** браки соседних ВИК 1921–22 на случай, если регистрировали по месту невесты: Деденевский д.276/300, Дмитровский ВИК д.277/301, Яхромский д.254/303, г. Дмитров д.226/299 (ЦГАМО ф.252 оп.1, шифры из komarov-revizii.md).
   - (б) **[запрос, по поручению]** архив ЗАГС Дмитровского г.о. / Главное управление ЗАГС МО: копия акта о браке Комарова Егора Петровича (~1888–91) и Натальи Алексеевны (~1901–02), Рогачевский ВИК, 1921–1922. Правнучка получает документ при подтверждении родства по цепочке свидетельств.
   - (в) **[запрос ЦАМО]** личное дело офицера: гв. лейтенант Комаров Николай Егорович, 26.02.1923, 30 гв. сп 8 гв. сд. В автобиографии и анкете офицера обычно указаны родители, иногда девичья фамилия матери и судьба отца. **Одновременно это лучший источник по цели 2** (отец жив/погиб/осуждён на 1940-е).
2. **Цель 2, Егор после 1923.**
   - (а) **[пользователь, ПН]** искать с местом рождения/призыва «Коммунистический р-н» / «Коммунистический РВК» и «Рогачевский РВК». Проверить ОБД «Книга памяти Московской обл.», том по Дмитровскому/Коммунистическому р-ну.
