# Родословная Комаровых, Снимщиковых, Зайчуков и Шутиссов

Древо: https://sokomishalov.github.io/komarova-genealogy/

- `case/` — дело исследования: реестры (люди, документы, утверждения, связи, журнал поиска), состояние, отчёты агентов, древо и PDF.
- `work/` — промежуточные материалы: скрипты, выгрузки страниц, распознанный текст. Сканы, PDF и прочие бинарные файлы лежат в `work/raw/` только локально.
- `tools/build_site.py` — собирает сайт `site/` из `case/tree.html` и `case/artifact-register.csv`. Живые люди на сайте только именем.
